## ⚡ Flagship — [Querya Desktop](https://github.com/QueryaHub/Querya-Desktop)

> A modern, high-performance database studio for **PostgreSQL · MySQL · MariaDB · SQLite · Redis · MongoDB**.
> Native on **Linux, Windows and macOS** — no JVM, zero telemetry.

| | |
|---|---|
| 🚀 **2D virtualized grid** | Millions of rows at 60/120 Hz with bounded memory |
| ✍️ **DML staging buffer** | Edit cells in place, review generated SQL, commit or roll back |
| 🗂️ **Multi-tab SQL studio** | Independent sessions, cancellable queries, searchable history |
| 🔒 **Private by design** | Credentials in the OS vault; nothing ever leaves your machine |
| 🧩 **Extensions** | Pluggable drivers, themes and commands |
