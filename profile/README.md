## Querya Desktop

A modern, high-performance database studio for **PostgreSQL, MySQL, MariaDB, SQLite, Redis and MongoDB**.
Native on Linux, Windows and macOS. No JVM, no telemetry.

| | |
|---|---|
| **Virtualized 2D grid** | Millions of rows at 60/120 Hz with bounded memory |
| **DML staging buffer** | Edit cells in place, review the generated SQL, commit or roll back |
| **Multi-tab SQL studio** | Independent sessions, cancellable queries, searchable history |
| **Private by design** | Credentials live in the OS vault; nothing leaves your machine |
| **Extensions** | Pluggable drivers, themes and commands |

[**Download**](https://github.com/QueryaHub/Querya-Desktop/releases/latest) &nbsp;·&nbsp; [Documentation](https://github.com/QueryaHub/Querya-Desktop/tree/main/docs) &nbsp;·&nbsp; [Roadmap](https://github.com/QueryaHub/Querya-Desktop/blob/main/docs/roadmap.md)
