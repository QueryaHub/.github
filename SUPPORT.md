# Getting help

- **Documentation:** [Querya Desktop docs](https://github.com/QueryaHub/Querya-Desktop/tree/main/docs) and the README of each project.
- **Bugs and feature requests:** open an issue in the relevant repository using the provided forms. Search existing issues first.
- **Security problems:** do not open an issue, see our [security policy](SECURITY.md).
- **Anything else:** [queryahub.com](https://queryahub.com/) or contact@queryahub.com.
